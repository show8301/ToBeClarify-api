# 店員提醒通知使用說明

> 版本：2.0｜更新日期：2026-09-10
>
> 本說明涵蓋已存在的初步功能與後續完整規劃；實際可用範圍依部署版本、通知開關及音效配置而定。
>
> 適用對象：店員、經理與開發者。
>
> 開發規格：[STAFF-NOTIFICATION-FEATURE.md](STAFF-NOTIFICATION-FEATURE.md)。

## 目前版本與後續功能

| 狀態 | 內容 |
|---|---|
| 程式已有，需確認部署啟用 | 八種個人提醒、廣播受眾／手動發送、廣播重複／堆積 episode、收件匣、歷史分頁、重連增量同步、音效上傳／試聽／停用、一般／置頂提示、已知道、緊急確認、撤回與確認進度 |
| 仍需外部確認 | 通知 flag／FFprobe／FFmpeg／真實三種系統音效、人工驗收與 dev／production 發布 |

目前畫面仍以音效下拉選單搭配鈴鐺狀態按鈕；收件匣先顯示近 30 天最新 100 筆，可按「載入更多」取得較舊紀錄。「目前清單全部已讀」只處理已載入清單。

以下操作說明以完整版本為目標；若畫面沒有對應選項，代表該部分尚未提供。三種系統音效需開發者實際上傳，不能只靠名稱就視為已有聲音。

## 1. 通知可以幫你做什麼？

你可以依自己的工作習慣，設定收到點餐、指名、香檳塔訂單，以及指名時段或開關店時間接近時的提醒。每一條規則都能各自設定彈窗與音效。

你的個人設定只影響自己。經理或開發者發出的店內廣播，則會通知廣播指定的人員，個人通知設定無法將它關閉。

即時提醒需要保持登入並開著後台頁面。切換後台功能頁仍可接收；登出、關閉網站或離開後台後，可在下次登入查看通知紀錄。

## 2. 到哪裡設定與查看？

在後台選單開啟「通知中心」。

| 位置 | 功能 |
|---|---|
| 我的通知 | 新增規則、設定聲音、管理自己的音效 |
| 店內廣播 | 經理／開發者管理全店提醒與手動廣播 |
| 頂部通知鈴鐺 | 查看未讀數、最近通知與相關訂單 |

點擊頂部鈴鐺會開啟通知抽屜，不必離開目前工作頁。通知紀錄保留最近 30 天；過期提醒可查閱，但不會再彈出或播放。

管理帳號尚未關聯店員身分時，仍能接收及管理有權限的店內廣播；建立個人規則前需要完成店員關聯。

## 3. 第一次使用

1. 進入「通知中心 → 我的通知」。
2. 點擊「啟用音效／試聽」，確認目前裝置可以播放。
3. 若希望切到其他分頁時也看到桌面提醒，點擊「允許桌面通知」並選擇允許。
4. 按「＋新增規則」，選擇通知時機及參數。
5. 選擇彈窗方式與音效，使用預覽確認。
6. 按「儲存設定」。

新帳號的個人規則預設為空，新規則預設一般提示、沒有音效。試聽或預覽不會發送真實訂單、通知其他店員或增加未讀數。

規則與音效會跟著帳號同步；每台裝置仍需分別確認聲音與桌面通知是否可用。

## 4. 可以設定哪些提醒？

| 通知時機 | 可以設定的內容 |
|---|---|
| 收到點餐訂單 | 是否啟用、彈窗與音效 |
| 收到指名訂單 | 監看對象、彈窗與音效 |
| 指名開始前 N 分鐘 | 監看對象、N、彈窗與音效 |
| 指名結束前 N 分鐘 | 監看對象、N、彈窗與音效 |
| 指名結束後 N 分鐘 | 監看對象、N、彈窗與音效 |
| 預定開店前 N 分鐘 | N、彈窗與音效 |
| 預定關店前 N 分鐘 | N、彈窗與音效 |
| 收到香檳塔訂單 | 是否啟用、彈窗與音效 |
| 店內待處理訂單堆積（管理者／開發者） | 待處理數量 K、持續 M 分鐘、重複間隔與最多次數 |

N 可以填 0–1,440 的整數。0 表示在該時間點提醒，例如「開始前 0 分鐘」就是開始時提醒；實際收到時間可能因連線與系統處理稍有延遲。

「點餐」指包含餐點／套餐的訂單，純指名、小費或房間服務不屬此項。待店內確認的訂單會標示狀態，收到通知不代表訂單已成立。

### 監看對象：定義已確認，功能待擴充

「我自己」監看自己的指名；「Someone：指定店員」監看你選擇的店員；「ALL：任一店員」監看所有店員的指名。

例如你選擇監看 B，只有你收到符合條件的提醒，不會替 B 新增設定；ALL 也不會把你的個人規則變成全店廣播。

### 香檳塔如何辨識？

新版菜單已有「香檳塔事件」開關。單品或套餐可以直接標記；套餐也會繼承子品的香檳塔分類。訂單會記住下單時的分類，不靠名稱猜測，商品之後改名也不會改掉這筆訂單的判斷。

同一筆訂單有多份香檳塔，仍只產生一次同類提醒。沒有勾選分類的商品，即使名稱含「香檳塔」也不會被當成香檳塔通知。

## 5. 用「＋」建立多段提醒

例如指名在 22:00 開始，你可以新增三條同類型規則：

| 規則 | 預計提醒時間 |
|---|---|
| 開始前 10 分鐘 | 21:50 |
| 開始前 5 分鐘 | 21:55 |
| 開始前 0 分鐘 | 22:00 |

三條規則可以使用不同聲音。完全相同的時機、對象與分鐘數不能重複儲存；想更換聲音時，直接編輯原規則即可。

規則可以複製後調整條件，也可以排序、停用或移除。按「儲存設定」後整組生效；未儲存前仍使用原本設定。若另一個分頁已修改同一組設定，系統會提示版本衝突，保留你的草稿供比對。

新增規則不會把過去訂單逐筆重播。

## 6. 選擇彈窗與聲音

彈窗與聲音分開設定。

| 彈窗方式 | 顯示效果 |
|---|---|
| 關閉彈窗 | 不跳出提示，但保留通知紀錄；仍可選音效 |
| 一般提示 | 角落出現小卡片，約 6 秒後收起 |
| 置頂提示 | 保留到你關閉，或提醒已失效 |
| 緊急確認 | 阻擋式視窗，必須按「已知道」；到期或撤回後解除 |

手機版提示出現在頂部。一般個人通知不會用要求確認的視窗打斷操作；緊急廣播會依序處理確認視窗。

| 音效圖示 | 代表意思 |
|---|---|
| 一般鈴鐺 | 尚未設定音效，這條規則不播放聲音 |
| 帶波紋的震動鈴鐺 | 已選擇音效，可點開查看名稱、更換或試聽 |

震動鈴鐺表示已設定聲音，不代表手機會震動，也不保證裝置已解除靜音。

如果只想看文字，選一般提示並保持無音效；只想聽聲音，關閉彈窗並選擇音效。兩者都關閉仍會留下通知紀錄；完全不想收這類個人提醒，請停用該規則。

## 7. 使用自己的音效

系統提供開發者準備的三種預設音效：新單提示、時間提醒、店內廣播。實際名稱以上線介面為準。你可將同一音效配給多條規則，也可以為各種提醒選不同音效。

在音效選擇器或「我的音效」上傳檔案、輸入名稱、試聽，儲存後即可選用。

| 項目 | 限制／建議 |
|---|---|
| 格式 | Ogg（Opus）或 MP3 |
| 長度 | 最長 5 秒，建議 0.5–3 秒 |
| 大小 | 最多 1 MiB，約 1 MB |
| 內容 | 清楚、短促、容易辨識的聲音 |

音效存在帳號的音效庫，可在其他裝置使用。個人音效只供自己存取及選用，系統音效由開發者管理。

個人音效可按「刪除」停用；系統音效不能刪除。若音效仍被規則、待發通知或有效通知使用，系統會拒絕停用，請先更換規則音效並等待相關通知失效。停用採軟刪除，既有通知歷史不會被改寫，檔案也不會由圖片資源清理流程刪除。單純更改副檔名不會把其他格式轉成合規音效。

## 8. 收到提醒之後

- 點「查看訂單」可開啟相關內容。
- 關閉提示只是收起畫面，不會自動接單。
- 「標記已讀」可整理未讀數。
- 店內廣播的「已知道」表示你已確認收到，不代表已接單或完成工作。
- 「全部已讀」不會代替緊急廣播的「已知道」。

同一事件符合多條規則時，會合併顯示，避免同時出現多張相同提醒。個人音效採排序最前且有選聲音的符合規則；全部無聲才不播放。

同時符合店內廣播時，以廣播畫面與音效優先。不同時間的提醒仍各自通知，例如提前 10 分鐘與當下不會合併。

廣播重複提醒會更新同一張通知卡，不會為每次重複建立新的收件匣卡片；卡片會顯示第幾次提醒。每條重複規則至少間隔 1 分鐘、最多 5 次，第一次提醒算第 1 次。收件者按「已知道」、廣播撤回、通知過期、來源解除或規則被修改後，後續重複會停止。

## 9. 指名改期、跨日與離線

- 指名提醒以有效已成立的排定時段為準。待確認或需改期的指名不發開始／結束倒數。
- 改期或縮短時段後，舊提醒會失效；取消的指名不再提醒。
- 「結束」不包含店員的緩衝時間。「結束後」是時間提醒，不表示訂單一定逾時未完成。
- 營業中的關店提醒會跟隨有效預定關店時間調整；實際提前開／關店後，無意義的倒數會取消。
- 例如晚上 22:00 開、隔日 02:00 關，關店前 10 分鐘在隔日 01:50 提醒。
- 離線後重新登入會載入未讀摘要，不把離線期間的個人通知全部播放一次。
- 尚有效且需要確認的店內廣播，登入後仍會顯示；到期或已撤回的廣播不再要求確認。
- 同一帳號開啟多個後台分頁時，系統會選一個分頁播放與呈現，其他分頁仍同步收件匣；主分頁關閉後會由其他分頁接手。
- 串流中斷時會帶最後 cursor 重連；若 cursor 已過期，會重新載入快照，不重播歷史聲音。

## 10. 經理／開發者：店內廣播

進入「通知中心 → 店內廣播」，可以設定事件規則，或立即發送手動／緊急廣播。

預設通知所有有效後台帳號，包含管理者；也可明確選擇今日上班者、指定角色或店員。未登入者不會即時聽到聲音，但會有收件紀錄。

建立規則時設定名稱、條件、通知對象、優先級、有效時間與系統音效；送出前確認畫面上的範圍。個人音效不能直接作全店廣播。

| 情境 | 建議 |
|---|---|
| 香檳塔訂單 | 全員、高優先、一次提醒；沿用菜單分類，配置音效後啟用 |
| 開關店或指名倒數 | 依店內需求啟用，一般或高優先 |
| 訂單堆積 | 設定待處理數量與持續時間，避免每張訂單都廣播 |
| 手動公告 | 輸入內容、範圍及有效時間後送出 |
| 緊急事項 | 填寫原因，要求收件者按「已知道」 |

緊急廣播入口不會自動發送消息，需要管理者操作。

預設有效時間為 15 分鐘，可設定 1–1,440 分鐘，時間型提醒還受事件有效時間限制。預設只提醒一次；需要重複時，間隔至少 1 分鐘、最多 5 次。

「待處理訂單堆積」不是每收到一張訂單就立刻再廣播。系統會計算目前 `STORE_CONFIRMATION_STATUS` 為待店內確認、且訂單仍在 submitted／partially_confirmed 佇列的訂單數；數量達到 K 並連續維持 M 分鐘後，才建立一個堆積 episode。數量降回 K 以下會結束 episode；之後再次達到條件會建立新的 episode。建議先用 K=3、M=5，再依尖峰時段調整。

收件者確認、事件解除、到期或撤回後停止相關重複提醒。管理者可以查看確認進度；如需取消已發出的廣播，使用「撤回」，只停用規則不會撤回已發內容。

送出後可查詢該廣播實例的收件、已讀、已知道、待確認、到期未確認與已撤回數量。撤回只移除該廣播來源；若通知卡同時包含個人提醒，個人提醒仍保留。

測試廣播只顯示給發起者，不發送全店。

## 11. 常見問題

### 鈴鐺已顯示有音效，為什麼沒有聲音？

先按「啟用音效／試聽」，檢查分頁、瀏覽器、電腦及喇叭是否靜音。如果顯示音效不可用，請重新選擇或上傳。音效播放失敗不會移除通知紀錄。

瀏覽器可能阻擋未經互動啟動的聲音，點擊試聽可協助確認播放狀態；實際限制依瀏覽器而異。[瀏覽器音效說明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)

### 為什麼沒有桌面通知？

確認已允許網站通知、瀏覽器支援且後台頁面仍開著。桌面通知主要用於切到其他分頁時；未支援或未允許時仍可使用站內通知。自訂音效由網頁播放，桌面通知本身的聲音由裝置決定。[瀏覽器通知說明](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API/Using_the_Notifications_API)

### 關閉網站後還會收到聲音嗎？

這一版需要開著後台並保持登入。關閉網站、裝置休眠或瀏覽器暫停頁面時，不能保證即時提示；下次登入可查閱紀錄。

### 我停用了個人通知，為什麼仍有廣播？

店內廣播由管理者設定，適用於符合指定範圍的人員，個人設定不會將它關閉。

### 同時開多個分頁會重複響嗎？

同一瀏覽器由其中一個分頁負責播放。不同裝置各自可能提醒一次；已讀和已知道會同步。

### 預覽會影響其他人嗎？

不會。音效、規則與廣播預覽只供自己檢查，也不會更改訂單。
